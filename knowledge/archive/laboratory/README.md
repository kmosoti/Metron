# Boolean laboratory archive

This archive preserves the historical Boolean-function laboratory evidence
from source revision [`898bae3d868fce6db3454a556a2afd91d246d7e1`](https://github.com/kmosoti/Metron/tree/898bae3d868fce6db3454a556a2afd91d246d7e1).
That revision contains the original executable sources, fixtures and run
inputs. They are retained there for provenance and are not part of the current
agent/harness product or its setup and verification workflow.

- `reports/`: committed Markdown/JSON outputs and report provenance.
- `manifests/`: historical inputs retained with the report evidence.
- `figures/`: historical figures; they are not regenerated by current product
  commands or required checks.
- `docs/`: historical laboratory architecture, invariants and milestone
  explanations. Their claims describe that source revision.

These files document bounded Boolean-laboratory findings. They do not establish
agent coding capability, current product architecture, or a reusable task
framework.
